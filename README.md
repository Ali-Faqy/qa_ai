## Open Code Review (OCR)https://github.com/alibaba/open-code-review

Open Code Review (OCR) هي أداة مفتوحة المصدر لمراجعة الكود باستخدام الذكاء الاصطناعي، وتساعد على اكتشاف الأخطاء البرمجية (Bugs)، ومشاكل جودة الكود، والثغرات الأمنية والمشاكل المحتملة داخل التغييرات التي يتم إجراؤها على المشروع. يمكن دمجها مع GitHub بحيث تعمل ضمن عملية التطوير بشكل تلقائي؛ فعند قيام المطور بعمل **Push** للتغييرات أو إنشاء **Pull Request**، تقوم الأداة بمراجعة التغييرات الجديدة (Code Changes / Diff) بدلًا من إعادة تحليل المشروع كاملًا في كل مرة. تقوم بمقارنة الكود الجديد مع النسخة السابقة، ثم تركز على الملفات والأسطر التي تم تعديلها أو إضافتها، وتحلل هذه التغييرات لاكتشاف Bugs أو مشاكل Security أو Code Quality. بعد ذلك يمكن أن تظهر نتائج المراجعة كتعليقات وملاحظات على الـPull Request، مما يسمح للمطور بمعالجة المشاكل قبل دمج التغييرات في الـmain branch. بهذه الطريقة تكون عملية المراجعة أسرع وأكثر تركيزًا، خصوصًا في المشاريع الكبيرة التي تحتوي على آلاف أو ملايين الأسطر من الكود.

## SonarQube / SonarSource

SonarQube هي منصة احترافية لتحليل الكود ومراجعته بشكل آلي، تم تطويرها بواسطة SonarSource. تقوم بتحليل الكود لاكتشاف الأخطاء البرمجية (Bugs)، والثغرات الأمنية (Security Vulnerabilities)، ومشاكل جودة الكود (Code Smells)، ومشاكل قابلية الصيانة (Maintainability)، بالإضافة إلى الديون التقنية (Technical Debt). كما تستطيع اكتشاف بعض المشاكل الأمنية مثل SQL Injection وXSS، وتوفر في الإصدارات التي تدعم ذلك تقنيات مثل Taint Analysis لتتبع البيانات التي يدخلها المستخدم ومعرفة ما إذا كانت تصل إلى أماكن خطرة داخل التطبيق. يمكن دمج SonarQube مع أنظمة CI/CD لفحص الكود تلقائيًا أثناء عملية التطوير وقبل وصوله إلى Production. توفر SonarSource إصدارات مجانية ومدفوعة؛ حيث يوفر الإصدار المجاني إمكانيات أساسية لتحليل جودة الكود، بينما توفر الخطط المدفوعة إمكانيات أمنية متقدمة وميزات إضافية للشركات والمشاريع الكبيرة.
